# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-24

### Added

- Architecture-aware Ubuntu 24.04 cloud-image setup for Apple Silicon and
  Intel Macs.
- Disposable qcow2 VM overlays backed by an unchanged base image.
- Cloud-init configuration for the local LFCS practice account.
- QEMU startup with SSH port forwarding.
- Reset workflow for recreating a clean practice environment.
- Setup, configuration, usage, and security documentation.
